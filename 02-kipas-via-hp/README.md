# Kipas via HP (Sanmey)

Menyalakan dan mematikan kipas dari HP lewat halaman web yang disajikan ESP32.

> **Catatan:** kode ini belum diuji di alat asli. Uji dulu sebelum dipakai, dan isi sendiri nama WiFi, password, token bot, serta alamat server.

## File
- `kipas_pintar.ino`

## Bahan
- ESP32
- Modul relay
- Kipas angin

## Wiring
- Relay IN > GPIO 26

## Library
- Bawaan ESP32 (WiFi, WebServer)
