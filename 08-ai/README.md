# AI: Regresi Linear dan Prediksi Hujan

Regresi linear untuk prediksi suhu, dan decision tree untuk prediksi hujan 1 jam ke depan. Data CSV adalah data contoh (dummy).

> **Catatan:** kode ini belum diuji di alat asli. Uji dulu sebelum dipakai, dan isi sendiri nama WiFi, password, token bot, serta alamat server.

- `prediksi-hujan/hujan.csv`
- `prediksi-hujan/flow_simpan_hujan.json`
