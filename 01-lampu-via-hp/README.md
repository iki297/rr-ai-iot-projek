# Lampu via HP (Rizky)

Menyalakan dan mematikan lampu dari HP lewat halaman web yang disajikan ESP32.

> **Catatan:** kode ini belum diuji di alat asli. Uji dulu sebelum dipakai, dan isi sendiri nama WiFi, password, token bot, serta alamat server.

## File
- `lampu_pintar.ino`

## Bahan
- ESP32
- Modul relay
- Lampu 220V

## Wiring
- Relay IN > GPIO 26

## Library
- Bawaan ESP32 (WiFi, WebServer)
